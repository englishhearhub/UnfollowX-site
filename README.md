# UnfollowX

**Unfollow non-followers & follow back fans on X — human-paced, transparent, with live stats and a full activity log.**

一键取关未回关的人、自动回关粉丝，真人操作节奏，批量管理你的 X 关注列表。

Chrome 扩展 · Chrome Extension — 本仓库是 UnfollowX 的主页与支持页面（源码为私有仓库）。

---

## Install / 安装

从 Chrome 应用商店安装 / Install from the Chrome Web Store:
👉 https://chromewebstore.google.com/detail/ahbokgehomgebcnlaaakjhaehalnflek

## Features / 功能

- ✓ 自动取关没有回关你的账号（互关绝不动）/ Auto-unfollow non-followers (mutuals stay safe)
- ✓ 自动回关关注了你的粉丝 / Auto follow back your fans
- ✓ 白名单保护：名单内的账号永不被取关 / Whitelist: marked accounts are never unfollowed
- ✓ 跳过最新 N 个、蓝 V、私密账号 / Skip newest N, verified, or protected accounts
- ✓ 真人节奏：随机间隔、批次休息、限流自动恢复 / Human-paced with automatic rate-limit back-off
- ✓ 实时统计与完整日志，后台也能跑 / Live stats & full log, works in background tabs
- ✓ 六种语言 / Six languages (EN / 简中 / 繁中 / 日本語 / 한국어 / ES)
